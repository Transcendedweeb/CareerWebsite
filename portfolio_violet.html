Project Violet

Stakeholders:Personal project

Date Finished:August 2021

Languages:Python

GitHub: Project Violet repo

Overview

Project Violet is a personal desktop assistant and real-time hardware monitor, designed to run on a compact LCD display. Built with Python and Pygame, it visualizes system performance—CPU, RAM, and disk usage—through dynamic speedometers and animated graphics.
Beyond monitoring, Violet also acts as a voice-controlled assistant. It responds to spoken commands to trigger quick system actions, display information like weather and time zones, or interact with modules configured by the user. The project blends functional system automation with a visually engaging interface that feels more like a living companion than a utility tool.

Features

- Real-Time Hardware Monitoring: Displays CPU, RAM, and disk usage with responsive speedometers, percentage indicators, and battery-style visuals.
- Voice-Controlled Commands: Integrated speech recognition allows Violet to respond to voice input for tasks like muting audio, showing weather updates, fetching local/global time, or launching system modules.
- Custom Animations & Interface: Includes animated sprites such as sakura leaves and Violet’s character design, giving the assistant a lively, interactive feel.
- Compact LCD Display Support: Designed to run seamlessly on a small 800×480 LCD screen, turning system stats into an interactive dashboard.
- Extensible Command System: Uses modular configuration files (.lnk, .url, .key, .cmm) so users can add custom actions, shortcuts, or text responses without rewriting core logic.
- Integrated Logging System: Actions and errors are tracked in log files, making it easy to debug and expand functionality.
