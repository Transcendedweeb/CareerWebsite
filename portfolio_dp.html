Dobbelspel Python

Stakeholders:Personal project

Date Finished:December 2023

Languages:Python

GitHub: Dobbelspel Python expirimental repo

Overview

The Python version of Dobbelspel marks the very first step in transforming a simple family board game into an interactive digital-physical hybrid. Using Python, the game connects a physical board—where dice rolls and player movement take place—with a PC interface that launches engaging minigames. These include a rock-paper-scissors duel, a rhythm-based challenge inspired by osu!, and a quiz module. While visually simpler than its Unity successor, this version established the entire framework for integrating physical input with digital play, making it the foundation of a long-term evolving project.

Features

- Arduino/Python Communication: Handles serial input from the physical gameboard to synchronize dice rolls and piece movements with the PC display.
- A best of 3 Rock-Paper-Scissors game between players.
- Osu-Inspired Challenge: Timing-based input mini-game
- Quiz Mode: Question and answer challenges.
- Uses Python scripts and libraries like pygame to render interfaces, manage turns, and trigger events.
- While lightweight compared to later versions, the architecture of this Python project laid the groundwork for the more polished Unity build by proving the feasibility of combining physical Arduino hardware with digital minigame logic.
